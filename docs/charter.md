# Charter

What the owner wants, in their words (2026-10-23): a very simple, very quick and efficient harness, shared structure first, that does what we do now by hand to build a repository step by step. It routes agent work across what we have on hand: a Claude Max plan (local Claude Code), Claude Code cloud sessions (monthly credits), Anthropic API credits and Codex, so no one pool carries everything. First user: Gauntlet's own build.

Background, not decisions: docs/research/ holds Void's sketch of the loop as it runs today, surveys of two existing tools (both verdict: borrow ideas, don't fork), the credit pacing plan, and the dispatch rules every agent follows.
